01 / DESIGN DIRECTION

像玩具一样亲近，
像工具一样开放。

让掌机不只是运行游戏的屏幕，而是承载每个人奇思妙想的小世界。

THE BIG IDEA

口袋里的游戏工作室

以横向掌机为基础，将熟悉的游戏手感和 AI 创作流程结合：创作在手机或电脑上完成，游戏在掌机上专心体验。

01 / FORM

圆润的一体式机身

大圆角、柔和背部弧线与微内凹按键区。建议尺寸约 190 × 85 × 20 mm，目标重量 250–300 g，最终以堆叠和手板验证。

02 / MATERIAL

柔雾触感，低饱和配色

PC+ABS 细纹哑光外壳，局部硅胶按键；推荐鼠尾草绿为主色，辅以奶油白和深森林绿。

02 / HARDWARE ARCHITECTURE

先做好一台掌机，
再打开创作入口。

建议首版采用成熟 Linux 计算模组，降低硬件与软件适配风险，优先验证「生成到游玩」闭环。

成熟计算核心
+ 定制掌机底板

核心板承载运算与系统；定制底板集成屏幕、按键、供电、音频与连接器。下图为逻辑连接，不代表具体引脚。

IN 按键 / 方向键 / 肩键 GPIO
CORE Linux ARM 计算模组 CPU + Wi-Fi
OUT 4.3″ 屏幕 / 扬声器 显示 + 音频
LINK USB-C / Wi-Fi 供电 + 数据
POWER 锂电池 / 充电 / 保护 电源管理
计算平台Raspberry Pi Compute Module 4 Lite 级别，建议 2GB RAM、带 Wi-Fi；或选供货稳定的同级 Linux 模组。
屏幕4.3 英寸 IPS，800 × 480，目标 300–400 nit；按模组接口选 DSI 或经验证的显示桥接方案。
操作十字键、ABXY、L/R 肩键、菜单与开始键；预留震动马达位置。首版不设摇杆以控制体积与成本。
存储与网络32GB microSD 起步，Wi-Fi 连接局域网；通过机内文件管理与版本回滚管理游戏包。
电源与续航3.7V 3000–4000mAh 锂电池，USB-C 5V 充电，带电池保护、温度监测及电量计；目标 3–5 小时，需实测。
音频与接口单声道扬声器 + D 类功放；一个 USB-C 外部口，需选支持设备模式的主控及匹配电路，实现充电和数据传输。
散热与结构导热垫连接金属散热片，必要时降频；螺丝固定后壳、可更换电池，避免封死维修路径。
工程边界：具体尺寸、屏幕接口、供电与 USB 设备模式依所选模组和屏幕数据手册确认；续航、温升及手感均需样机验证。若换用其他模组，需同步验证驱动与长期供货。
03 / AI CREATION INTERFACE

给 AI 留一扇门，
而不是把 AI 塞进机身。

首版采用云端或电脑侧 AI 生成，掌机只负责接收、校验和运行游戏，不依赖本地大模型。

01 / PROMPT

说出游戏想法

在手机或电脑的创作页面描述玩法、画面和规则，可选择掌机按键模板。

02 / GENERATE

AI 生成标准游戏包

AI 按 SDK 生成 HTML5 游戏，附清单、封面和资源；创作端先预览并校验。

03 / TRANSFER

一键送到掌机

同一局域网配对后上传；USB 数据模式作为工程备选，支持离线导入游戏包。

04 / PLAY

在掌机上开玩

设备校验包体并安装到游戏库，以受限 Web 容器运行；失败可回滚或删除。

建议开放的最小接口 / LOCAL API
POST /v1/games  ·  GET /v1/games  ·  POST /v1/games/{id}/launch
配对授权 · 游戏包上传 · 安装状态返回
游戏包约定：manifest.json（ID、版本、入口、按键映射）、index.html 和本地资源，封装为 ZIP；提供分辨率、存档及按键 API 的 SDK 与示例。AI 通过创作端调用接口，不直接拥有系统权限。
安全默认：一次性配对码 + 设备令牌；校验包大小、路径与格式，限制游戏文件访问和网络权限，禁用任意系统命令。局域网明文仍有窃听风险，生产版应采用 TLS 或等效加密。

量产前重点：电池与充电安全、运输测试、无线电及 EMC 认证、目标市场合规、儿童使用年龄分级、游戏内容审核与售后可维修性，均应在设计冻结前纳入计划。
